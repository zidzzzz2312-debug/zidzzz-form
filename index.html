Hubungkan database

ZIDZZZ Forms memakai Supabase sebagai database online. Buat project Supabase gratis, lalu masukkan URL project dan publishable/anon key.

Kredensial disimpan hanya di browser ini. Jangan pernah masukkan service_role key.
Belum punya database? Lihat petunjuk setup
  1. Buka supabase.com, buat project.
  2. Di Project Settings → API, salin Project URL dan anon/public key.
  3. Buka SQL Editor → New query, lalu jalankan SQL di bawah ini.
